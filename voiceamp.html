安裝至手機桌面 / Chrome 應用

📱 Android / Chrome 手機版：

點擊瀏覽器右上角 「⋮」選單 → 選擇 「加到主畫面」 或 「安裝應用程式」，即可像原生 App 一樣全螢幕開啟。

🍎 iPhone / iPad (Safari)：

點擊底部中央 「分享」圖示 → 往下滑動並選擇 「加入主畫面」。

💻 電腦版 Chrome / 上架部署：

點擊網址列右側的 「安裝」圖示 即可獨立視窗運行。若要上架至 Google Play 或 Chrome 生態系，只需將此單一 HTML 檔案託管於任何 HTTPS 網址（如 GitHub Pages / Vercel），即可透過 PWABuilder 打包上架。
